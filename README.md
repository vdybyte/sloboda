# Слобода (Sloboda)

Мод-колонии для **Minecraft 26.3 · Fabric**. Основываешь слободу, размечаешь зоны, а поселенцы сами рубят лес, сносят добро в амбар и строят избы. Чем больше изб, тем больше жителей.

## Что есть в версии 0.1.1 (MVP)

| Что | Как работает |
|---|---|
| **Вечевой камень** | Ставишь — основана слобода радиусом 64 блока, приходят строитель и лесоруб, в склад кладутся стартовые припасы (64 дубовых бревна, 16 хлеба, 8 саженцев). ПКМ — сводка. Shift + ПКМ — открыть склад. Разбил — слобода распущена, склад высыпается. |
| **Амбар** | Окно в общий склад слободы (54 ячейки). Все амбары одной слободы показывают одно содержимое. Жители носят грузы к ближайшему. |
| **Межевой кол** | ПКМ по двум углам — зона. Shift + ПКМ — режим: жилая / лесная / стереть. Пока кол в руке, границы зон и слободы подсвечиваются искрами. |
| **Лесоруб** | Валит деревья целиком (сначала в лесной зоне, без неё — в радиусе 24 блоков), сажает саженец на место пня, носит брёвна в амбар. Постройки не трогает. |
| **Строитель** | Находит ровное место 7×7 в жилой зоне, забирает из амбара брёвна (61 шт. любых пород) и строит избу блок за блоком: пол, бревенчатые углы, дверь, окна, крыша, верстак, лучина. Порода избы — та, которой больше всего в амбаре (работает и с тополем из 26.3). |
| **Возчик** | Подбирает всё, что валяется в слободе (саженцы из листвы, яблоки и т. п.), и сносит в амбар. |
| **Рост** | Каждая изба даёт +2 места. Раз в минуту, если есть место и 2 еды в амбаре, приходит новый житель. Ремесло выбирается по нужде (лесорубов вдвое больше остальных). |
| **Жители** | ПКМ — что делает и что несёт. Shift + ПКМ — сменить ремесло. Убегают от монстров, лечатся со временем, не уходят далеко от слободы. |

## Рецепты

- **Вечевой камень**: каменные кирпичи по углам, медные слитки по сторонам, золотой слиток в центре.
- **Амбар**: доски, сноп сена сверху, сундук в центре.
- **Межевой кол**: красная шерсть над двумя палками.

## Быстрый старт в игре

1. Поставь Вечевой камень на ровном месте.
2. Возьми Межевой кол, кликни два угла жилой зоны (например, 20×20 рядом с камнем).
3. Shift + ПКМ колом → «лесная зона», размечай участок леса.
4. Поставь Амбар. Подкидывай туда еду и брёвна, чтобы слобода росла быстрее.

## Сборка

Нужно: **JDK 25**, интернет (Gradle скачает Minecraft и Fabric).

**Вариант А — IntelliJ IDEA 2025.3+**
Открой папку проекта → дождись импорта Gradle → задача `build` (или `runClient`, чтобы сразу запустить игру с модом).

**Вариант Б — командная строка**
```
./gradlew build        # Windows: gradlew.bat build
```
Готовый мод: `build/libs/sloboda-0.1.1.jar` → положи в `.minecraft/mods` вместе с Fabric API 0.164.0+26.3 (или новее) на Fabric Loader 0.19.5+.

**Вариант В — без установки JDK**
Залей проект в репозиторий GitHub. Сборка запустится сама (`.github/workflows/build.yml`), jar появится во вкладке Actions → артефакт `sloboda-jar`.

## Устройство кода

```
ru.sloboda
├── Sloboda                 — точка входа, регистрации, тик слобод
├── registry/               — блоки, предметы, сущность, вложение мира
├── block/                  — Вечевой камень, Амбар
├── item/SurveyStakeItem    — Межевой кол и разметка зон
├── colony/
│   ├── Colony              — данные слободы, склад, рост, планировка участков
│   ├── ColonyData          — все слободы мира (Fabric Data Attachment на ServerLevel)
│   ├── HousePlan, WoodSet  — чертёж избы под любую породу дерева
│   └── ColonyTicker        — раз в секунду: рост, проверка камня, подсветка зон
└── entity/
    ├── SettlerEntity       — поселенец: котомка, ремесло, сохранение
    └── ai/                 — Job (база), WoodcutterJob, BuilderJob, CarrierJob
```

Сборка рассчитана на нынешний тулчейн Fabric для 26.x: Loom `net.fabricmc.fabric-loom` 1.17.20 без ремапа (Minecraft не обфусцирован), официальные имена Mojang, Gradle 9.6, Java 25.

## Совместимость с 26.3

Код сверен с исходниками Fabric API (ветка 26.3) и со списками изменений Minecraft 1.21.9 → 26.3. Что учтено:

- `Identifier` вместо `ResourceLocation`, сохранение через `ValueInput`/`ValueOutput`
- взмах рукой — `swing(рука, SwingAnimation)` (изменено в 26.3)
- творческая вкладка — `FabricCreativeModeTab.builder()`
- рендер — ванильный `EntityRenderers.register` (Fabric-овский `EntityRendererRegistry` устарел) и свой слой модели через `ModelLayerRegistry`, без зомби-слоёв, которые переделывали в 26.1–26.3
- никаких `codec()` у блоков (убраны в 26.3), данные мира — Fabric Data Attachment на `ServerLevel`
- рецепты и модели предметов в формате 26.x (`items/*.json`, ключи рецептов строками)
